The art style for *Sediment* has to be well executed, this is currently one segment of the game I find difficult to resolve. ![[sediment buidling 1.png]]
![[building_artstyle_test1 2.jpg]]

These are some of the first art tests I did regarding the environments. This workflow consisted of modelling the base environment, building, structure in Blender, and then going into an editing software like Photoshop and making the picture look like a stamp or collage. This is achieved by giving the buildings a colour overlay and then expanding it a bit around the edges so it gets that collage feel. The visuals being applied over the models is a mix of grain and stamp/edge filters. 

This could probably also work well with a dithering pattern applied over it, it would probably fit the game better, a test which you will read more about right about...
